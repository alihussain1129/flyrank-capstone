# FlyRank Front-End AI Engineering Capstone

This repository contains my capstone project for the FlyRank Front-End AI Engineering Internship.

## Overview

This project is being developed using AI-assisted development practices. It demonstrates the use of modern development tools, Git, GitHub, and AI coding assistants.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js
- Git
- GitHub
- Cursor AI

## Project Goals

- Learn AI-assisted software development
- Follow Conventional Commits
- Build a production-quality frontend project
- Practice version control using Git and GitHub
